# Nubus Portal

This repository contains the Nubus Portal (former "Univention Portal").

The Nubus Portal is a landing page for End Users which shows a
personalized list of applications End Users can access and
gives access to Nubus UIs like End User Self Service or the
Management UI (Univention Management Console).

The Nubus Portal is heavily customizable - visible content as well
as look & feel can be completely configured.

More information can be found in the documentation on
https://docs.software-univention.de/nubus-manual/latest/en/portal.html#univention-portal
